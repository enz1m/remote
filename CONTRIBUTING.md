# Contributing

Reuse enzUI widgets, theme tokens and native services. Keep protocol workers off
the UI thread, bound frames and peer-controlled input, and reject callbacks from
retired sessions. Preserve host verification, input release, credential isolation,
transfer custody and crash-safe persistence. Never log or commit private state,
credentials or authenticated endpoints.

Run formatting, the focused behavior suite and strict Clippy from the README.
Keep coverage for protocol negotiation, parser limits, host trust, credentials,
storage, input, uploads and shutdown. Consolidate related cases; shared widget
behavior and tests of source spelling belong outside the application suite.

Check native wide and narrow windows, both themes, file activation and affected
protocol flows against disposable local servers. Bind retained screenshots to
the actual binary and window. Tests and screenshots must not claim a fixture
is a live provider session. Keep temporary fixtures and review data under
ignored AGENTS/; curated images belong in docs/screenshots. Translations live in
assets/locales.

Use the system upstream SPICE GLib library. Keep the Moonlight dependency pinned
to its reviewed source. Do not edit shared SDK caches or replace system libraries.
