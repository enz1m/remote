# Remote contributor notes

Use enzUI widgets and theme tokens for shared controls. Protocol implementations
remain embedded; never replace them with an external desktop client or describe
simulated connections as real. Keep capability limits explicit.

Preserve strict host trust, credential isolation, bounded frames and input cleanup.
Keep credentials out of SQLite, exports, logs and screenshots. Test with isolated
local servers and disposable state; never seed ordinary user profiles.

Use normal Cargo commands with the system spice-client-glib library. Personal
limits and temporary fixtures belong under ignored AGENTS/. Do not edit shared
framework sources or replace system libraries.

Keep tests for protocol negotiation, trust, storage, credentials, input, transfer
custody and shutdown. Remove duplicate widget/source-shape checks and consolidate
related workflows. Check real wide/narrow windows, light/dark themes and affected
protocol connections. Curated screenshots belong in docs/screenshots; translations
live in assets/locales. Stage explicit paths and preserve private user profiles.
